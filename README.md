# บ้านอุ่น - แอปสั่งอาหารในร้าน

โปรเจกต์ React Native + Expo สำหรับงานกลุ่มวิชา 01418342

## ตอนนี้ทำอะไรได้

- เลือกโต๊ะ 1-15; โต๊ะที่มีบิลอยู่ใช้สีต่างจากโต๊ะว่าง
- ดูเมนู 5 หมวด หมวดละ 5 รายการ รวม 25 รายการ
- เลือกจำนวน ใส่หมายเหตุ ส่งรายการเข้าครัว และสั่งเพิ่มหลายรอบ
- ดูบิลของโต๊ะและเปลี่ยนสถานะอาหารในหน้าครัว

**ระยะนี้ยังไม่เชื่อมฐานข้อมูล** ข้อมูลการสั่งเป็น `useState` จึงหายเมื่อปิดแอป ส่วนการเก็บบิลย้อนหลังและข้อกำหนด SQLite ใน PDF ยังต้องทำในระยะถัดไป

## วิธีรัน

```bash
npm install
npx expo start
```

เปิดด้วย Expo Go แล้วเลือกโต๊ะเพื่อเริ่มทดลองสั่งอาหาร

## โครงสร้างไฟล์

- `App.js` เก็บ state และฟังก์ชันสำหรับการสั่งอาหาร พร้อมเลือกหน้าที่แสดง
- `src/screens/` เก็บหน้าโต๊ะ เมนู ตะกร้า บิล และครัว
- `src/components/` เก็บปุ่ม หัวหน้า และแถบเมนูที่ใช้ซ้ำ
- `src/theme.js` เก็บสีและ style ของแอป
- `src/data.js` เก็บข้อมูลหมวดหมู่และเมนูตัวอย่าง

# บ้านอุ่น - แอปสั่งอาหารในร้าน

โปรเจกต์ React Native + Expo สำหรับงานกลุ่มวิชา 01418342 การพัฒนาแอปพลิเคชันบนอุปกรณ์เคลื่อนที่

แอปจำลองการสั่งอาหารภายในร้าน โดยลูกค้าและครัวใช้งานคนละหน้าจอในแอปเดียวกัน ข้อมูลหลักเก็บใน SQLite บนเครื่อง

## ความสามารถของแอป

- เลือกโต๊ะ 1-15; โต๊ะที่มีบิลอยู่ใช้สีต่างจากโต๊ะว่าง
- ดูเมนู 5 หมวด หมวดละ 5 รายการ รวม 25 รายการ
- เลือกจำนวน ใส่หมายเหตุ ส่งรายการเข้าครัว และสั่งเพิ่มหลายรอบ
- ดูยอดรวม ปิดบิล และดูประวัติบิลที่ปิดแล้ว
- ดูรายการในหน้าครัวและเปลี่ยนสถานะเป็นรอทำ กำลังทำ หรือเสิร์ฟแล้ว
- ดูรายงานยอดขายและเมนูขายดี รวมถึงรีเซ็ตข้อมูลการขายเพื่อทดสอบใหม่

ข้อมูลโต๊ะ เมนู ตะกร้า ออเดอร์ และบิลเก็บใน `expo-sqlite` จึงยังอยู่หลังปิดแล้วเปิดแอปใหม่ แอปนี้จำลองหน้าลูกค้าและครัวบนเครื่องเดียวกัน ยังไม่มีการซิงก์ข้อมูลข้ามเครื่อง

## วิธีรัน

```bash
npm install
npx expo start
```

เปิดด้วย Expo Go แล้วเลือกโต๊ะเพื่อเริ่มทดลองสั่งอาหาร

## โครงสร้างไฟล์

- `App.js` เปิด SQLite และเชื่อมข้อมูลกับหน้าจอต่าง ๆ
- `src/database.js` สร้างตารางและใส่ข้อมูลเริ่มต้น
- `schema.sql` แสดงโครงสร้างตารางและดัชนี
- `src/screens/` เก็บหน้าโต๊ะ เมนู ตะกร้า บิล ประวัติบิล ครัว และรายงาน
- `src/components/` เก็บปุ่ม หัวหน้า และแถบเมนูที่ใช้ซ้ำ
- `src/theme.js` เก็บสีและ style ของแอป
- `src/data.js` เก็บข้อมูลหมวดหมู่และเมนูตัวอย่าง
